# Stilprobe: 5 Richtungen x 5 Motive

> Zum Reinkopieren in ein Bildmodell. Ziel: eine Entscheidung ueber die
> Material- und Lichtsprache, bevor 48 Motive produziert werden.
> Auf Englisch, weil Bildmodelle damit zuverlaessiger arbeiten.

## So laeuft es

Fuenf Durchgaenge. Pro Durchgang **einmal** den Basis-Block plus **eine**
Stilzeile. Immer dieselben fuenf Motive, sonst vergleichst du Motive statt Stile.

Die Motive sind bewusst gewaehlt: zwei mit Gesicht, drei **ohne**. Gerade Geste,
Herz und Krug sind die Stellen, an denen ein Satz kippt, weil die Versuchung
gross ist, ihnen Augen zu geben.

---

## Basis-Block (bleibt in jedem Durchgang wortgleich)

```
A set of 5 icons in one consistent style, arranged in a single row on a plain
flat background, evenly spaced, all rendered with the SAME camera, the SAME
lighting and the SAME optical weight.

The 5 subjects, in this order:
1. a fox
2. a thumbs-up hand
3. a heart
4. a beer mug
5. a dragon

Hard rules, they define the set:
- Faces ONLY on the fox and the dragon. The hand, the heart and the mug have NO
  face, no eyes, no mouth. This is critical.
- Where there are eyes: small, matte, no specular highlights, no eyelashes.
  Calm, attentive expression. No smiling. No blushing cheeks. Not cute.
- Matte surface throughout. No gloss, no plastic shine, no rim highlights.
- One soft key light from the upper left at roughly 35 degrees, identical on all
  five, plus faint ambient fill from the lower right. A soft contact shadow
  under each object so it reads as a physical thing, not a sticker.
- Each object carries one small warm glow inside it, like a firefly is sitting
  in it. Subtle, not a lamp.
- Every object is slightly tilted, never perfectly upright.
- Slight handmade irregularity: uneven edges, small dents, nothing machine
  perfect.
- Simplified forms. No fur strands, no individual feathers, no scales.
- Muted, warm, desaturated colours. No candy colours.
- No outlines, no text, no background scenery, no reflections.
- All five objects fill the same visual weight: the dragon must not dominate
  the heart.

Square framing, each object centred in its own cell, generous margin.
```

## Die fuenf Stilzeilen (je Durchgang genau EINE anhaengen)

**A. Weiche Tonknete**
```
Style: soft matte modelling clay, hand-shaped, gentle thumb marks visible,
slightly porous surface, warm and tactile.
```

**B. Filz und Wolle**
```
Style: crafted from felt and wool, visible fibre texture, soft stitched seams,
slightly fuzzy silhouette edge, textile warmth.
```

**C. Papierschnitt**
```
Style: layered cut paper, two or three stacked paper planes per object, soft
paper edges casting tiny shadows on the layer below, matte uncoated paper,
risograph-like muted ink tones.
```

**D. Bemaltes Holz**
```
Style: hand-painted carved wood, visible grain under the paint, slightly worn
paint edges, matte varnish, the look of a wooden toy made by a craftsman.
```

**E. Weiches Vinyl**
```
Style: matte soft-touch vinyl designer toy, smooth rounded volumes, seam line
where the mould halves meet, premium collectible object, no gloss.
```

## Einstellungen

* Seitenverhaeltnis breit (die fuenf nebeneinander), sonst quadratisch pro Motiv
* Pro Richtung **denselben Seed** verwenden, damit die fuenf Motive innerhalb
  einer Richtung zusammenpassen
* Hintergrund flach und einfarbig, damit sich spaeter sauber freistellen laesst
* Keine Beschriftung im Bild

## Worauf wir beim Ansehen achten

1. **Haben Hand, Herz und Krug ein Gesicht bekommen?** Wenn ja, hat die Richtung
   die Regel nicht gehalten, und sie wird es bei 48 Motiven auch nicht.
2. **Sieht die Reihe aus wie eine Werkstatt?** Gleiches Licht, gleiches Gewicht,
   gleicher Winkel. Ein Ausreisser genuegt, damit der Satz billig wirkt.
3. **Wirkt es erwachsen, ohne kalt zu sein?** Das ist der eigentliche Test.
4. **Traegt der Stil ueber 48 Motive?** Manche Materialsprachen sind bei fuenf
   Motiven reizvoll und bei fuenfzig ermuedend.
